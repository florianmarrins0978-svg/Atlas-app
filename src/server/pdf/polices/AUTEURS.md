**Les noms réservés se respectent** : la licence interdit de redistribuer une
version modifiée sous le même nom. Ces fichiers sont tels que Google Fonts les
sert, non modifiés — c'est aussi pourquoi ils ne sont pas sous-ensemblés ici.
Le sous-ensemblage se fait à l'embarquement, dans le PDF, ce que la licence
autorise puisqu'il ne redistribue pas la police.
