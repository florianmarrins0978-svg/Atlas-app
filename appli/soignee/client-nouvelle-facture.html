La suite est l’écran que vous connaissez déjà, celui de Terminés, « Créer une facture » : les travaux, puis la facture.

Ce qui change

  • Sur la fiche d’un client, un geste de plus : Nouvelle facture. Il ouvre l’écran de « Créer une facture », le client déjà rempli.
  • Quatre gestes se rangent deux par deux, chacun garde sa hauteur pour le pouce. Trois restent sur une ligne.
  • Rien de neuf derrière : l’écran de facture sait déjà prendre un client (lu dans le code). C’est un bouton.

Ce qui ne bouge pas

  • « Dernier devis », « Nouveau devis », « Contrat d’entretien », les onglets Devis, Factures, Fiches.
  • « Créer une facture » dans Terminés, pour un client qu’on choisit sur place.
