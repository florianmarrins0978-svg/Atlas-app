Vos devis et factures

PDF, photos ou dossier .zip. Ce qui est lu se range chez M. Bernard, sans chercher son nom dans le document.

Ce qui change

  • Sur la fiche d’un client, un geste de plus : Importer devis / facture, les mots du bouton de « Vos clients ».
  • Il ouvre l’import que vous connaissez, déjà attaché à ce client : un devis venu d’une autre application se range chez M. Bernard, même si le nom écrit dessus est autre.
  • Quatre gestes se rangent deux par deux, chacun garde sa hauteur pour le pouce. Trois restent sur une ligne.

Ce qui ne bouge pas

  • « Dernier devis », « Nouveau devis », « Contrat d’entretien », les onglets Devis, Factures, Fiches.
  • « Importer devis / facture » de « Vos clients », qui range chaque pièce par le nom qu’il y lit.
