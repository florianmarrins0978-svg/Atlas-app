Ici l’application s’ouvre, comme après « Entrer ».

Ce qui se passe derrière

  • Le code est celui de la création du compte : 6 chiffres, valable un quart d’heure, un nombre d’essais limité.
  • L’e-mail dit : « Votre code pour changer de mot de passe. Si vous n’avez rien demandé, ignorez ce message. »
  • Une adresse sans compte mène au même écran, et aucun e-mail ne part. Sans cela, n’importe qui pourrait tester quelles adresses ont un compte Atlas.
  • Une fois le mot de passe changé, tous les autres appareils sont déconnectés. Si quelqu’un d’autre était entré, il est dehors.
  • On entre directement dans Atlas, sans retaper le mot de passe.
