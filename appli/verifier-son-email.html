Ce qui change

  • Six cases au lieu d'une gélule avec « 000000 », qu'on prenait pour un code déjà rempli. L'iPhone propose toujours le code lu dans Mail.
  • Les chiffres passent à 27 px, la case qui attend le chiffre suivant est cerclée d'or.
  • L'adresse quitte le titre. Elle ne se coupe plus au milieu d'un mot en gros caractères.
  • « Retour » monte en haut à gauche, comme sur les autres écrans de la porte. Il n'est plus collé sous « Renvoyer le code ».
  • Quand le code a expiré, le gros bouton devient « Renvoyer le code ». On n'appuie plus sur « Continuer » devant une case vide.
  • « Renvoyer le code » se lit plus clair et se touche sur toute sa largeur.
