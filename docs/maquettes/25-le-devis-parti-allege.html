Et le bouton « carré »

Vous l'avez dit : « le bouton est toujours carré, pas arrondi comme tous les autres ». Voici ce que j'ai mesuré avant de dessiner — et pourquoi vous avez raison sans que le bouton soit en cause.

Ce bouton a déjà exactement le même rayon que les cartes : 4 px. Ce n'est donc pas un oubli. Mais un rayon de 4 px sur un aplat vert foncé ne se voit pas : le coin est franc, l'œil lit un carré. Sur une carte crème posée sur un fond crème, le même rayon se lit — le contraste est cent fois plus faible, et le coin fond dans la page.

Autrement dit : pour paraître aussi arrondi qu'une carte, un bouton plein doit être plus arrondi qu'elle. Choisissez ci-dessous — la carte grise sous chaque bouton porte le même rayon, pour que vous jugiez les deux ensemble.
