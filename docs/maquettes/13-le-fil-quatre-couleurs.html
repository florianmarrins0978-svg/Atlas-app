Le fil — quatre couleurs

Sans le trait sous ATLAS

Le cheveu qui séparait le nom du « Bonjour Florian » a disparu : le haut respire d’un seul tenant jusqu’au trait qui ferme l’en-tête. Tout le reste est celui que vous venez de garder.

Le fil

Plus aucune boîte. Un trait vertical traverse la liste et porte les jours, comme une tige. Une seule perle s’y pose — sur le chantier qui attend votre réponse.
